## 2. Mathematical corrections made
- section_uniqueness_bounded_comparison.tex:4 (overview). Old: "An auxiliary solution whose density is larger on a strict sublevel set of $u-v$ then forces this set to have zero mass". New: "...larger on the set where $u>v$ yields small perturbations $q$ of $u$ for which $\{v<q\}$ has zero mass...". Why: this is a direction error. The proof uses S = {v<u}, a strict superlevel set of u-v, and only the subsets {v<q_delta} are shown to be null, not S itself.
- section_uniqueness_extrema.tex:215-217. The dense two-component criterion said "at most two components with disjoint closures ...". It now argues explicitly: assume G_+ != G_-, so these are the two components; their closures cover X, so connectedness forces them to meet. Why: the old wording did not handle the one-component case, and "at most two ... with disjoint closures" was logically loose.
- section_gauduchon_surface_uniqueness.tex:4. "the error is exactly the pairing of $w^2$ with $\ddc T$" became "exactly half the pairing", to match eq:mixed-uniqueness-defect, which has the factor 1/2.

- section_uniqueness_bounded_comparison.tex:25. "\int f\,\omega^n" became "\int_Xf\,\omega^n" (domain of integration added).
