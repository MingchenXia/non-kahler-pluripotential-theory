## 3. Suspected problems not fixed
None are substantive. The following are notation clashes for coordination:
- **$W$**: in `hessian:weighted-cone-trace` (cone file), $W:=\sum_iF_iM_{i\bar i}$. The trace section uses $W=g^{-1}H$ for the matrix and $W_M$, $W_v$ for weighted traces. **Proposed fix:** rename the cone lemma's $W$ to $W_M$.
- **$H$**: the trace section uses $H_{i\bar j}=g_{i\bar j}+u_{i\bar j}$. Elsewhere, $H(v)=(v_{i\bar j})$ (Liouville, complex limits), $H$ is a smooth function and $H_m(w)$ the Hessian operator (proper approximation). In complex limits I added "as in \cref{sec:hessian-liouville}" to separate them. A rename (for example $\widetilde H_{i\bar j}$ in the trace section) is a larger, non-local change, so I did not make it.
- **$g$**: the Liouville proof writes $\omega=\mathrm i g\,dz\wedge d\bar z$ with a factor $\kappa$, while the trace section uses $\omega=\frac{\mathrm i}{2\pi}g$. This is harmless because only constants change, but it is two meanings of $g$ in adjacent sections.
- **$K,L,M,q$**: reused in complex limits (compact set, trace bound, metric bound, test function) with meanings different from the trace section. Each is local and unambiguous there.
- **Evans–Krylov–Caffarelli**: complex_limits:153 recalls the interior $C^{2,\beta}$ estimate for viscosity solutions of concave operators with Hölder $x$-dependence as "classical", without a citation. The allowed book GT01 covers only classical solutions. This is not an error, but `chapter_history.tex` may want to attribute the viscosity version.
- **Unused term**: the $d\lambda_1\mathcal F$ term in the conditional proposition is never used ($d=0$ in the application). It is harmless and I left it.
