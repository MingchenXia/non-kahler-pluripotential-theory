## 3. Suspected problems not fixed
1. **`section_bounded_hermitian_smoothness.tex:126`** ("The local Evans--Krylov estimate therefore gives $u\in C^{2,\beta}$"). This applies the estimate to $u$, which is known here only as a *viscosity* solution of $\mathcal F(x,D^2u)=u+G(x,u)$. The classical Evans–Krylov estimate (GT Chapter 17, and the one used in `cor:classical-higher-estimate`) is an a priori estimate for $C^2$ solutions. The step is correct if one uses Caffarelli's viscosity version. `chapter_history.tex:191` cites TWWY15, Theorem 3.4 "and the paragraph following it", which may cover this; the coordinator should confirm it.
   **Proposed short repair that avoids viscosity solutions:** after obtaining uniform $C^{1,\alpha}$ bounds for the $a_j$, solve once more $\omega_{b_j}^n=\mathrm e^{b_j+G(x,a_j)}\omega^n$. `lem:prescribed-potential-trace` (with $M'=\sup|G|$) gives uniform ellipticity, so the $b_j$ are uniformly bounded in $C^{1,\alpha}$. The right-hand side $b_j+G(x,a_j)$ is then uniformly $C^\alpha$, so the classical Evans–Krylov estimate gives uniform $C^{2,\beta}$ bounds. Finally, $b_j\to u$ uniformly by the same bracketing with $\|G(x,a_j)-G(x,u)\|_{C^0}\to0$.
2. `lem:fixed-trace-gradient-interpolation` is referenced nowhere in the book except `chapter_history.tex:176`. Either a result should use it (for example the Hessian chapter), or the author may want to know that it is standalone.
3. `section_uniqueness_cofactor.tex:76`: the author's `\Needspace{7\baselineskip}` sits mid-paragraph. `\needspace` issues `\par`, so "In the real coordinate order…" now starts a new indented paragraph. This is typographic only; I left it.
