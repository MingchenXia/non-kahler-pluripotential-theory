\section{Obstacle envelopes}
\label{sec:obstacle-envelopes}\index{Envelope!obstacle}

An obstacle selects the largest potential lying below it. The local upper-envelope theorem gives the construction once the competitors have a common upper bound; normalized compactness supplies that bound for an obstacle finite almost everywhere or prescribed on a non-pluripolar compact set.

A smooth real $(1,1)$-form $\theta$ is called \emph{big} if there are $\rho\in\PSH(X,\theta)$ and $\delta>0$ such that
\[
 \theta+\ddc\rho\geq\delta\omega.
\]
Here $\omega$ is any Hermitian metric. Changing that metric changes $\delta$, not the condition. Neither this definition nor the existence of $\theta$-plurisubharmonic functions requires $\theta$ to be closed.

For any smooth real $(1,1)$-form $\theta$ and an extended-real obstacle $f$ on $X$, defined at least outside a pluripolar set, write
\[
 P_\theta(f)=\left(\sup\{v\in\PSH(X,\theta):v\leq f
                      \ \hbox{q.e.}\}\right)^*.
\]
For $u,v\in\PSH(X,\theta)$, set $P_\theta(u,v)=P_\theta(\min(u,v))$. The empty supremum is $-\infty$. For an upper semicontinuous obstacle, the pointwise definition gives the same competitors: a quasi-plurisubharmonic function lying below it almost everywhere lies below it everywhere, by the local submean inequality and upper semicontinuity of the obstacle.

To apply the local upper-envelope theorem while retaining the lower bound $-\theta$, fix a constant positive form $\kappa$ in local coordinates. For each $\epsilon>0$, shrink the neighborhood and choose a constant form $\theta'$ with $-\epsilon\kappa\leq\theta-\theta'\leq\epsilon\kappa$. A smooth potential $r$ for $\theta'+\epsilon\kappa$ makes every competitor plus $r$ plurisubharmonic. The local envelope theorem then gives $\theta+\ddc P_\theta(f)\geq-2\epsilon\kappa$ there. Letting $\epsilon$ tend to zero proves the exact bound. The same local theorem shows that regularization changes the supremum only on a pluripolar set.

Here is a useful way to check the upper bound for an unbounded obstacle. If $f\leq A$ for a real constant $A$ on a Borel set $E$ of positive $\mathrm{d}V$-measure and $h\leq f$ is a competitor, normalize $\widetilde h=h-\sup_Xh$. By \cref{thm:normalized-compactness},
\[
 (\sup_Xh-A)\operatorname{Vol}(E)
 \leq\int_E|\widetilde h|\,\mathrm{d}V\leq C_\theta
 \quad\hbox{whenever }\sup_Xh>A.
\]
Thus the competitors have a common upper bound. In particular this applies to any measurable obstacle finite almost everywhere, by taking one of its finite sublevel sets of positive volume.

An obstacle bound on a non-pluripolar compact set also bounds every competitor globally, even when that set has zero smooth volume.

\begin{lemma}\label{lem:compact-obstacle-upper-bound}
Let $\theta$ be a smooth real $(1,1)$-form on the connected compact manifold $X$, let $K\subseteq X$ be compact and non-pluripolar, and let $w\in C(K,\mathbb R)$. There is a constant $C=C(\theta,K,w)$ such that every $a\in\PSH(X,\theta)$ satisfying $a\leq w$ quasi-everywhere on $K$ has $\sup_X a\leq C$.
\end{lemma}
\begin{proof}
Otherwise choose such functions $a_j$ with
\[
 M_j:=\sup_Xa_j\geq 2^j+\max_Kw.
\]
The normalized functions $v_j=a_j-M_j\leq0$ have uniformly bounded $L^1$ norms by \cref{thm:normalized-compactness}. Choose $A>0$ with $\theta\leq A\omega$. The partial sums
\[
 s_N=\sum_{j=1}^N2^{-j}v_j
\]
decrease, have uniformly bounded $L^1$ norms, and satisfy $\ddc s_N\geq-A\omega$. Thus their limit is a genuine quasi-plurisubharmonic function $s$; the $L^1$ bound excludes the identically $-\infty$ alternative in the local decreasing-limit theorem.

Let $N_j\subseteq K$ be a pluripolar exceptional set for the $j$-th obstacle inequality. On $K\setminus\bigcup_jN_j$ one has $v_j\leq-2^j$ for every $j$, hence $s=-\infty$. The set where a genuine quasi-plurisubharmonic function is $-\infty$ is pluripolar. Together with the countable union of the $N_j$, it would contain all of $K$, contradicting the hypothesis on $K$.
\end{proof}

\Needspace{12\baselineskip}
If $\PSH(X,\theta)$ is nonempty, its normalized envelope
\[
 V_\theta=P_\theta(0)
\]
is $\theta$-plurisubharmonic. Indeed, a normalized $\theta$-plurisubharmonic function is a competitor, and the family is bounded above by zero. Moreover,
\[
 u-\sup_Xu\leq V_\theta\qquad(u\in\PSH(X,\theta)).
\]
A potential $v\in\PSH(X,\theta)$ has \emph{minimal singularities} if $u\preceq v$ for every $u\in\PSH(X,\theta)$.\index{Minimal singularity} The displayed inequality shows that $V_\theta$ has minimal singularities, and every such $v$ satisfies $v\sim V_\theta$. If $\theta\geq0$, then $V_\theta=0$.

\begin{lemma}\label{lem:bounded-below-envelope}
Let $\eta$ be a smooth semipositive real $(1,1)$-form on $X$. If an obstacle $f$ is finite almost everywhere and bounded below quasi-everywhere by a constant, then $P_\eta(f)$ is a bounded $\eta$-plurisubharmonic function.
\end{lemma}
\begin{proof}
The lower constant is a competitor. The preceding finite-sublevel argument gives a common upper bound for all competitors. The local envelope theorem therefore gives a bounded envelope.
\end{proof}

\Needspace{12\baselineskip}
\begin{proposition}
\label{prop:continuous-obstacle-envelope}
If $f$ is continuous and $\omega$ is Hermitian, then $P_\omega(f)$ is continuous. Moreover,
\[
 \|P_\omega(f)-P_\omega(g)\|_\infty\leq\|f-g\|_\infty
 \quad(f,g\in C^0(X)).
\]
\end{proposition}
\begin{proof}
The constant $\min_Xf$ is a competitor, so $p=P_\omega(f)$ is bounded. The local envelope theorem gives $p\leq f$ quasi-everywhere, and continuity of $f$ makes this inequality pointwise. Choose smooth $v_j\downarrow p$ by \cref{thm:bounded-exact-regularization}. For every $\epsilon>0$, the continuous functions $v_j-f$ decrease to a function at most zero. Compactness shows that $v_j\leq f+\epsilon$ everywhere for all large $j$: otherwise their decreasing compact $\epsilon$-superlevel sets would have nonempty intersection. Hence $v_j-\epsilon$ is a competitor and
\[
 p\leq v_j\leq p+\epsilon.
\]
Thus $v_j\to p$ uniformly, proving continuity. The last inequality follows directly from the competitors and
$P_\omega(g+c)=P_\omega(g)+c$ for constants $c$.
\end{proof}

\begin{definition}\label{def:singularity-envelope}\index{Envelope!ordinary singularity}\index{Model potential!envelope fixed point}
For $u\in\PSH(X,\theta)$, set
\[
 P_\theta[u]
 =\left(\lim_{C\to+\infty}P_\theta(u+C,0)\right)^*
 =\left(\sup\{h\in\PSH(X,\theta):h\preceq u,\ h\leq0\}\right)^*.
\]
We call $u$ an \emph{envelope fixed point} if $P_\theta[u]=u$.
For $F\in C^\infty(X,\mathbb R)$, replacing the constraint $h\leq0$ by $h\leq F$ defines $P_{\theta,F}[u]$.
\end{definition}

The two formulas agree by taking the union of the competitor families. They also agree with the definition using $V_\theta$ in place of zero: every $\theta$-plurisubharmonic competitor below zero is below $V_\theta$. The envelope is a genuine potential, since the competitors contain $u-\sup_Xu$ and are bounded above by zero. In particular, $u\preceq P_\theta[u]$. The last relation is not an assertion that the two functions differ by a bounded amount.

Directly from the competitors, $P_\theta[u]$ is unchanged when $u$ is replaced by a potential of the same ordinary singularity type, and
\[
 u\preceq v\quad\Longrightarrow\quad P_\theta[u]\leq P_\theta[v].
\]
These statements concern ordinary singularities. Replacing $\preceq$ by the multiplier-ideal order would define a different operator, which will require a separate comparison.

For a bounded obstacle in a big background, exceptional sets in the competitor inequality can be removed by a small singular perturbation.

\begin{lemma}
\label{lem:big-pointwise-competitor}
Let $\theta$ be big, let $f$ be bounded, and let $u\in\PSH(X,\theta)$ satisfy $u\leq f$ quasi-everywhere. There are genuine $u_t\in\PSH(X,\theta)$, $t>0$, such that $u_t\leq f$ everywhere and $u_t\to u$ almost everywhere as $t\downarrow0$.
\end{lemma}
\Needspace{12\baselineskip}
\begin{proof}
Choose $\rho\in\PSH(X,\theta)$ with $\theta+\ddc\rho\geq\kappa\omega$ for some $\kappa>0$. The exceptional set $E=\{u>f\}$ is pluripolar. The global form of Josefson's theorem on compact complex manifolds supplies a genuine quasi-plurisubharmonic $\chi$ with $\chi=-\infty$ on $E$; see \cite[Theorem 1.1.5]{SGPT}. Rescale and normalize it so that $\chi\leq0$ and $\ddc\chi\geq-\omega$. Shift $\rho$ so that $\rho\leq\inf_X f$. With $s=t/\kappa$, put
\[
 u_t=\frac{u+t\chi+s\rho}{1+s}.
\]
All three potentials are finite almost everywhere, so this is genuine. Moreover
\[
 \theta+\ddc u_t
 =\frac{\theta+\ddc u+t\ddc\chi+s(\theta+\ddc\rho)}{1+s}
 \geq0.
\]
Outside $E$, each of $u$ and $\rho$ is at most $f$, while $\chi\leq0$, so $u_t\leq f$. On $E$ the numerator is $-\infty$. Finally $u_t\to u$ wherever all three potentials are finite, which is a set of full measure.
\end{proof}

Minimal singularities separate a potential from the poles of a strict analytic barrier. This gives a proper function on its regular locus.

\begin{lemma}\label{lem:interior-proper-gap}
Let $\rho\in\PSH(X,\theta)$ have analytic singularities with smooth remainder and satisfy $\theta+\ddc\rho\geq\varepsilon\omega$ for some $\varepsilon>0$. Set $\Omega=\{\rho>-\infty\}$. If $\varphi\in\PSH(X,\theta)$ has minimal singularities and is continuous on $\Omega$, then $\varphi-\rho$ is continuous, bounded below, and proper on $\Omega$: all its sublevel sets are compact in $\Omega$.
\end{lemma}

\begin{proof}
Translate $\rho$ and $\varphi$ so that $\rho\leq0$ and $\sup_X\varphi=0$, and choose $C$ with $\varphi\geq V_\theta-C$. These translations do not affect properness. Choose $M\geq0$ with $\theta\geq-M\omega$. If $a\in(0,1)$ is sufficiently close to one, then
\[
  \theta+\ddc(a\rho)
  =a(\theta+\ddc\rho)+(1-a)\theta
  \geq\bigl(a\varepsilon-(1-a)M\bigr)\omega>0.
\]
Thus $a\rho$ is an admissible competitor for $V_\theta$. Minimal singularities and the normalization give
\[
  0\geq\varphi\geq V_\theta-C\geq a\rho-C,
\]
and hence
\begin{equation}\label{eq:interior-gap-proper}
  \varphi-\rho\geq(1-a)(-\rho)-C.
\end{equation}
By hypothesis $\varphi$ is continuous on $\Omega$; $\rho$ is smooth there because it has analytic singularities. Hence $\varphi-\rho$ is continuous. Since $\rho\to-\infty$ when approaching $X\setminus\Omega$, \eqref{eq:interior-gap-proper} places every sublevel set in a compact superlevel set of $\rho$. The sublevel set is closed in $\Omega$, so it is compact there.
\end{proof}
