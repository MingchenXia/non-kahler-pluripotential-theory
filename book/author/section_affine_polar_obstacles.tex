\begin{corollary}\label{cor:affine-polar-obstacle-invariance}
The envelope $F_\delta$ is unchanged if $u|_K\leq\psi$ is imposed only quasi-everywhere, or only on $K\setminus E$ for any pluripolar $E\subseteq K$.
\end{corollary}
\begin{proof}
By \cref{lem:affine-projective-growth}, the map $u\mapsto u-\delta\chi/2$ is a bijection from the competitors for each of these weakened constraints onto the $\theta_\delta$-plurisubharmonic functions satisfying the same constraint with the obstacle $\psi-\delta\chi/2$. Apply \cref{prop:compact-obstacle-polar-invariance} on $\mathbb P^n$ to the K\"ahler, hence big, background $\theta_\delta$ and this bounded obstacle on $K$, and add $\delta\chi/2$ as in the proof of \cref{prop:affine-projective-envelope}.
\end{proof}

These equalities concern regularized envelopes. The raw envelope $V_\delta$ is still defined with the obstacle imposed at every point of $K$.
